接入前，你需要准备什么？
  1. 在这台 Mac 上登录工作微信。
  2. 安装并验证 wx-cli 的设备兼容与密钥条件。
  3. 启动只监听本机的采集服务（默认 9100 端口）。
  4. 回到这里检测连接，确认账号后只选试点群。
macOS 27.0 / 微信 4.1.15.55 尚未实测兼容。应用不会自动修改微信签名或关闭系统保护；如果工具要求这些变更，请先停在该步骤核对。
服务已装好？查看启动参考
wx-cli --version
wx-cli doctor
wx-cli status
wx-cli server run --host 127.0.0.1 --port 9100
以上以所选 wx-cli 版本实际支持为准。没有有效数据库密钥时，仅启动 server 不能完成采集。密钥不要粘贴到本页面或聊天。
