# Wechat-Agent

Use agent to manage Wechat

个人微信商家客户管理助手：聚合私信与普通微信群里的业务信息，形成商家档案、跟进任务和历史客户激活建议。对外消息由用户在微信中人工确认并发送。

当前仓库处于设计阶段，尚未实现可运行应用。本文档中的命令、接口及目录为拟实现契约，不代表已验证功能。

## 第一阶段范围

所有消息、档案、任务与分析均在本地处理。先使用虚构样例和人工整理的聊天导入，跑通完整业务闭环；再验证真实微信采集，不以第三方采集工具可用作为整个项目启动的前提。

- [业务工作流](docs/01-workflow.md)：用户每天如何处理消息、跟进商家和激活历史客户。
- [本地技术设计](docs/02-local-implementation.md)：模块、存储、接口、分析与同步契约。
- [实施与验收计划](docs/03-local-validation.md)：开发顺序、本地运行方案和测试场景。

第一阶段不接入云服务器、Tailscale、外部模型 API、自动发送或自动加好友。未来扩展以本地闭环的实际结果为依据。
