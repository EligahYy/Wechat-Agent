# 沟通原文日历双栏设计（用户已确认）

2026-11-15。采用左日历、右当天消息详情。首次进入直接显示双栏，优先当月本人最新发言日期，必要时定位最近本人发言／有效私聊记录，来源默认为全部，左栏约280px，切日期只更新右侧。资料概览与消息原文采用一致窗口宽高及内容淡入，不再先单栏再突然放大。窄屏折叠为日期入口，不挤压正文。日期统一北京时间。

来源须有本人实际发言或可验证私聊，单纯群成员关系不成立。日历仅本人有发言日期显示蓝点，移除灰点，选中日期强调，今天独立标记，切月不改变右侧正在阅读的日期。右侧顶部固定日期、搜索和来源筛选；原文独立滚动，保留本人当天发言会话中所有人的相关上下文，已验证私聊单独兼容。本人高亮用柔和底色，当前条目左侧强调，去掉整圈蓝框。右上角紧凑圆角浮条仅计数和上下箭头，作用于当天＋来源＋关键词范围，到首尾禁用不跨日。

取消加载更早／更多按钮；当天按需分批读取，只在用户滚动到边缘时继续读取，向上补入保持可见锚点。无本人消息的群日期不展开无关上下文；有效私聊仅我方消息仍可查看。空日明确显示暂无记录。回到最新保持来源范围，选择当前来源最近本人发言日期（无本人发言时回退有效私聊）、定位当天末尾；保留关键词且无匹配时明确显示空结果，不触发同步或模型。

保留同客户日期、筛选、本人定位和独立阅读位置；换客户重置。菜单沿用现有顶层、主题、焦点及减少动态效果。宽屏窗口适度加宽，窄屏通过日期入口折叠日历。当前全历史线性浏览被本方案取代，无需保留旧分页按钮。
