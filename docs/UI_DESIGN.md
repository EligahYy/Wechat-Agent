# 工作台视觉与交互规范

2026-11-08 · 重建 M0。参考 Apple 生态的信息层级、系统控件和连续反馈；不是官网营销页的复制。配套 [可操作原型](UI_PROTOTYPE.html) 全为虚构数据，不连接微信或模型；本轮正式界面仍为旧版，待 M1 接入新客户状态。

## 信息架构

一级导航只有今日、客户、数据、设置。宽屏左栏224px，内容最大1120px；窄屏顶部横向导航，详情改为全屏。页面标题始终说明当前任务，不放技术队列术语。今日的该联系／待确认／等待中按客户计数，客户卡内再显示事项数。一个客户可在不同任务页签出现，但同一页签只有一张卡。

客户详情独立深层视图：真实姓名与微信定位、当前下一步、关键确认、初步沟通、活跃批次、历史、来源。默认不展开长聊天。返回保留搜索、页签、页码和滚动位置。正式版路由可恢复，不依赖弹框中的孤立状态。

## 页面细节

### 今日

顶部一句当前状态和查看进度入口；主体优先显示可执行客户卡，不堆大屏数字。卡片包括真实称呼、当前批次／初步沟通、联系理由、明确时间标签。每卡一个主操作“查看并处理”，次操作收进详情。等待中不涂成紧急色。时间标签紧凑单行，长文字转正文。

详情展示微信备注／群名／时间锚点，“复制定位信息”反馈成功才提示已复制。复制草稿不更新联系状态。完成、改期、暂停需明确对象；完成可撤销，重新读取后端版本；冲突返回“内容已更新，请核对”并展示当前状态，不能乐观提示成功后静默失败。

### 客户与确认

搜索支持备注、昵称、已确认店铺；输入防抖250ms，取消或忽略过期请求；无结果提供清除搜索。默认客户概览，不是聊天列表。一个客户多个确认在详情归组；选择带证据的候选值，保存前明确将修改什么。“暂不判断”不等于确认。证据按来源ID去重展示，关联到不同判断时保留关系。

### 数据与范围

接入、整理覆盖、范围管理分区。正常处理／免跟进用分段页签，当前页签只提供相应操作。支持人物／会话类别、搜索、每页最多50条、总数、上一页／下一页。切换范围和搜索清空勾选；批量操作显示对象数，提交期间禁用重复提交；失败保留选择，成功就地移除并提供撤销。

进度区分归档、近期分析、历史补齐、图片未读；显示分母和更新时间。无需行动是有效结果，不能当失败；源端离线、预算等待、模型失败各有简短解释和适用动作。正式版禁止把模拟进度／用量当真实数据。

### 设置

账号与连接、模型与预算、偏好、备份分组。密钥保存成功后仅展示已配置；自检不调用推理。展开诊断才显示端口／错误码。重建显示备份、处理范围及新代际状态，不能将“准备检查”标成“重建完成”。

## 动效与输入反馈

| 交互 | 动效／反馈 |
| --- | --- |
| hover/press | 120ms颜色变化；按钮按下缩放0.98，列表行不缩放 |
| 页签 | 160ms底色变化；选中态不只靠颜色，支持键盘左右键 |
| 页面切换 | 180ms透明度＋纵向4px；不逐卡延迟加载动画 |
| 详情 | 220ms侧向12px＋透明度；返回焦点到触发按钮，Esc关闭 |
| 状态改变 | 立即显示忙碌，服务端确认后更新；失败贴近操作显示 |
| Toast | polite live region，普通提示4秒；涉及撤销至少8秒，另保留历史恢复入口 |
| 骨架屏 | 仅真实加载显示；超过1秒说明正在处理，失败后停止循环 |

使用ease-out曲线(0.2,0.8,0.2,1)，不做夸张弹簧和无限光效。尊重prefers-reduced-motion，关闭位移、缩放、平滑滚动；无动画也必须有完整状态反馈。

## 通用状态与可访问性

每个数据区域必须定义加载、正常、空、搜索无结果、失败、过期、无权限／已排除、部分覆盖。空白不能一律叫“暂无待办”。危险操作避免与高频操作挨在一起。触控目标至少44px，键盘焦点可见；对话框有名称、焦点圈定、Esc与关闭按钮，关闭恢复焦点。长名称换行，技术ID折叠，320px宽不产生横向滚动。

验收使用桌面、390px和320px视口、系统深色、减少动态效果、键盘流程；操作完成与撤销、名单分组与分页、空结果、详情返回位置都要实际运行。原型验证布局和流程，不代替正式API的失败／版本冲突测试。

## v0.11.1 交互约束

详情四个页签使用等宽网格和相同点击高度，不随选中状态或待确认数量改变按钮尺寸；窄屏保证文字不截断。页签提供tab／tabpanel关联及方向键、Home、End切换。侧栏按钮统一宽度、起点和最小44px高度。

分册用原生可收起控件，加载中也允许收起；响应返回不强制展开，再次打开复用已加载内容。线索处理提供编辑核实、不采纳、撤销和持久结果；保存其他线索不清空尚未保存的编辑。打开详情不清空客户搜索和筛选。
