## 已交付

- 本机 wx-cli 只读采集私信与群聊；名称同步、历史补齐、一个可选文件导入入口。保留原文、来源修订、身份和隔离记录。
- 按真实联系人归集完整授权历史，先分册再总结客户、备货批次、行动和确认；不做价值预过滤。近15天活跃优先，不截断每人的早期历史。
- 持久客户队列、增量更新、分册复用、失败重试与退避、账号与来源授权、群聊／人物免跟进名单。
- 开始／暂停／继续／重试共用任务命令，计数与卡片读取同一份后端状态；只有实际持有客户运行锁才提供“暂停分析”，旧运行记录不冒充正在执行。
- 页面收敛为数据大屏与设置。大屏上方为有跟进任务的客户，下方为其他客户，两组使用相同五列且一人只出现一次，各自每页20位。搜索、档案、待确认、任务与整理操作在同一行；已完成整理保留客户行，不再提供暂停／继续。单客户暂停跨刷新、重启、新消息和全局开关保留。暂停后不发布该轮未完成档案。一次分析连续完成合并、总结、复核与保存，不再每12次请求要求人工继续；原始分册覆盖与当前阶段进度分开显示。
- 合并分册按更小组执行，截断／格式异常支持拆分恢复，保留已完成分册；错误仅记录安全字段路径。文本整理与草稿不设每日Token上限，只记录用量。
- 客户详情、来源证据、待核实线索编辑／不采纳／撤销、人工跟进、行动状态、批次阶段锁、短话术草稿；生成草稿不代表已联系，微信仍由用户发送。
- 图片本机预览与本地OCR候选，核对文字后带版本进入后续分析；原件不外发。
- 设置内统一账号、授权、监控、用量、手动导入与白名单。人物／群聊会话分开管理，白名单不出现在大屏分组、搜索或统计；私信排除统一归入人物；群内已识别成员随群全局免跟进，保留来源关系，恢复群不清掉手动或其他群的排除。共享排除规则，原文不删除。原页面仅显式`/legacy`兼容。

schema v16升级前生成`pre-v16-*.sqlite3`，聊天、客户版本、分册、名单、用量与自动开关保留，无需重导。升级不会自动开启此前关闭的自动整理；旧预算和请求次数检查点恢复排队，人工暂停保留。

## 尚需验证或后续交付

- 真实微信只覆盖源端可见、已同步历史；源端群成员／昵称／引用消息覆盖与Mac Vision识别质量仍需实机验证。
- DeepSeek的商家归属、跨群同批、发货与新需求判断需要真实样本验收；程序回归通过不代表业务准确率达标。
- 暂无长期经验学习、多Agent、向量库、自动微信发送；完整派生代际发布／回滚、价卡素材结构化及历史激活策略仍为后续工作。
