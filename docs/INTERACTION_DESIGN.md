# 当前交互与视觉方案

更新：2026-11-15（北京时间）。正文描述当前规则；未实现的档案编辑等单独标注。实际交付与测试以[STATUS](STATUS.md)为准，用户新确认优先于历史原型与归档方案。

## 1. 页面与工作台

主导航只有工作台和设置，左上角EU标识。工作台有商家档案／业务活跃联系人两页签；设置中的全量联系人管理是维护入口，不增加第三个主导航。

顶部统一“同步并整理”和“整理记录”。全局同步刷新联系人与会话、读取消息，再仅对业务范围内确认商家规划整理；非商家只归档。来源完成与模型完成分开显示；未接入分析不能显示资料已更新。不另设主页刷新联系人按钮，独立元数据接口仅诊断使用。

整理记录点击条目后在该条目下原位展开，再次点击收起；只展开一项。切换条目取消旧详情请求，加载失败在选中项内重试。从客户“查看同步详情”进入时定位到对应详情，不沿用上次列表滚动位置。

联系人搜索只匹配姓名／备注和实际补位显示的群内姓名；不匹配wxid、群名、未展示历史别名。同名不同ID不合并。来源与缺名说明可核对，不能复制群名片冒充全局微信名。

身份筛选全部／商家／服务商／平台／待识别。跨页多选仅限已选具体ID，切工作台页签清空选择；勾选不重建行，操作栏双向平滑展开收起。

## 2. 联系人管理与身份

设置→管理全部联系人：查看完整归档，姓名检索、范围筛选、单人／批量加入移出。身份与业务范围独立，人工移出最高优先，自动条件和新同步不能加回。逐人显示人工加入／移出、确认身份、近期直接互动或群需求识别待完成等理由。

单人“修改身份”在按钮附近展开菜单，点击选项立即保存；方向键只移动焦点，Enter提交，Esc取消并回到触发按钮。批量身份保留确认弹窗。部分版本冲突明确显示结果并重新核对，不能静默覆盖。

## 3. 客户详情

头像、姓名、身份和复制入口只在头部显示一次；wxid弱化放下一行。右侧商家“同步并整理此客户”，其他身份“同步该联系人消息”，旁边关闭。同步／整理进度和错误在该客户窗口内显示，范围匹配，不冒充别人的任务。

复制仅复制当前可确认的全局备注／昵称，缺名禁用。反馈置于原生弹窗上方，不被背景遮罩模糊，不抢焦点。

当前页签是资料概览和沟通原文。备货记录及真实资料卡由M2后续任务实现；不能为占位状态生成示例档案。旧的来源定位／覆盖统计侧栏不恢复；消息日历属于沟通原文内部导航。

## 4. 沟通原文：日历双栏

首次进入沟通原文就展示双栏，默认全部来源，优先读取当前月本人最新发言日期，月内无发言时定位最近发言，完全无本人发言时回退已验证私聊，不再停留在日历单栏。资料概览与原文共用稳定的客户弹窗宽高，内容以轻微淡入过渡，减少动态效果时停用。左侧月历与右侧当天对话各自可操作。选中日期、今天和有记录标记区分；日期统一北京时间，切换月份不改变正在阅读的日期，支持年份／月份菜单和跨月键盘定位。

右侧固定日期、搜索和来源筛选，正文独立滚动。日内本人发言按稳定发送者ID高亮，普通本人消息浅底色，当前定位稍深底色与左侧强调；去掉整圈蓝色描边，身份标签颜色保持。

右上角紧凑圆角浮条叠放在消息上层，不预留独立行或顶部占位空白；仅计数和上下箭头，按钮保留可访问名称和禁用边界。导航作用于当前日期＋来源＋关键词，不把提及或同名人物算作本人发言。蓝点只表示本人发言，群上下文只来自本人当天发言的群；已验证私聊仅我方消息仍可查看。

取消“加载更早／更多原文”按钮，实际有方向的边缘滚动才按需补页，程序定位、点击正文不触发。上方插入保持可见锚点，日期／来源／关键词变化取消旧请求；不把旧范围结果混在新标题下。失败就近显示，保留明确重试。

回到最新定位当前来源最近本人发言日期（无本人发言时回退有效私聊）和当天末条消息，保持关键词，不隐式同步或调用模型。空日与无匹配明确区分。特殊转发记录显示类型占位，文件／引用／链接只展示可读摘要，系统／撤回通知隐藏；原文证据与附件引用仍完整归档。

已加载本人消息就地高亮和滚动，不请求窗口、不重新播放列表入场动画；跨窗口保留当前消息与计数，失败可继续重试。月份及窗口缓存各最多6项、30秒有效，归档／身份更新使缓存失效。

同客户页签返回保留日期、来源、关键词和阅读位置；关闭或换客户后重置。宽屏保留约280px日历，窄屏折叠日期入口。具体实现见[日历设计](superpowers/specs/2026-11-15-timeline-calendar-design.md)及[验收记录](verification/calendar-message-browser-report.md)。

## 5. 设置与公共控件

设置卡片统一标题栏、图标、分隔和内容行：联系人管理、本机数据与模型、每日整理、外观、消息导入。模型保存只写非敏感配置及本机Keychain，不触发供应商请求；显式连接检查用最小无客户资料请求，检查通过不代表窗口容量／视觉通过。

每日开关和时间当前只保存配置，调度待M4。时间行只有08:30与内嵌时钟，时区放选择面板内；支持直接输入及24小时双列选择，草稿应用后保存，取消／Esc／外点不保存，关闭每日计划时一起禁用。

输入使用共享FormField，48px基础高度、12px圆角、14px文字；搜索、多行、密码和时间保持同一边框／焦点／错误／禁用语义。下拉使用SelectField，自定义列表支持键盘、取消、滚动、避边及弹窗顶层，输入离开可见区才收起，退出阶段不再可点。

## 6. 尚待M2任务4—7的资料界面

资料概览展示有来源的具体摘要和沟通状态，货品／物流各一张完整卡，字段保持对齐，不把每项拆成小卡。每卡有查看来源和编辑资料，来源显示真实发送人、时间、会话和必要前后文，折叠可平滑反转。

备货记录按独立批次展示，允许录入多个单号，不因录入自动标走货。编辑分组标题16px，货品信息／属性货量、路线目的地／运输服务／费用关注、补充资料分组清晰。人工补充用备注，不实现任意自定义字段管理器。

人工更改检测版本冲突、保留草稿与人工标记，不改写原文或静默覆盖新模型值。当前模型发布、人工纠正和真实资料界面未完成，不把本节视为已有能力。

## 7. 视觉、动效与验收

系统字体、主色#0066cc；深浅色同步覆盖背景、文字、卡片、控件、弹窗和菜单。主标题36/600，弹窗22—24/600，分区18/600，分组16/600，正文与输入14，字段／操作13，辅助与常规标签12；原文内部ID与紧凑标签可用11。常规标签28px、原文紧凑标签24px。

导航指示器、筛选、勾选栏和页面内容局部过渡；按钮悬浮保持位置。常用过渡160—340ms；搜索／切换取消旧请求，不积压动画；按系统或应用减少动态效果设置降级。窗口按内容测量高度，菜单跟随实际触发位置，不缩放文字。

验收覆盖1180／1280／1440／1920桌面宽度及较矮视口，公共控件样式、快速反向操作、焦点／Escape、深浅色及减少动态效果。客户页签共用稳定尺寸，首次原文自动进入最新全部来源双栏；实际验证和保留限制见STATUS。
