# 重建交付状态：v0.7.1 / M1 技术试点

2026-11-08。当前已实现可操作的新工作台和客户文档引擎，尚未通过用户真实聊天与 DeepSeek 的业务质量验收。M1技术闭环可试用，M1业务验收待完成；不是全量自动CRM切换。

## 已交付

- `/workspace` 使用真实本地归档，不使用原型虚构数据。原工作台导航提供入口。
- 一个真实联系人对应一份版本化客户文档；包含初步沟通资料、批次、下一步和客户内确认。不会从旧AI客户、摘要、任务导入推断。
- DeepSeek有限执行：每次最多3次模型请求、1次范围内关键词检索；保存响应、用量和安全错误码，原文可追溯；相同来源与文档结果可直接复用。
- 人工完成、暂停和角色决定有版本校验；人工约束保留，过期模型响应不能覆盖。角色提供商家／非目标／暂不确定选项，其他确认目前为文字约束。
- 人物／会话免跟进在新引擎读取、写入和展示中生效；源修订／范围变化使旧档案暂时退出展示；重新分析后更新有效依据。
- 当前源数据已有新进展但未整理、上下文不足、未明确商家或姓名无法定位时，不发布今日联系建议。模型不能直接写库。
- 本地联系人发现与模型授权分离，兼容仅有发出消息的私信及身份明确但方向未知的群消息。提供备注／昵称搜索、空列表原因、设置直达及刷新；未授权只能查看候选，不能分析。
- 联系人试点选择每页50条，运行详情显示最近20次状态、真实调用数和错误；多个进程不能同时请求同一联系人。
- `start --pilot` 保留采集及历史归档，暂停原模型后台；新模型只在手动选择联系人时执行。全局授权、预算与网络配置继续共用。
- schema v10 增加客户文档、修订和执行记录；从已有库升级先产生 `pre-v10-*.sqlite3`，原消息、名单、旧业务结果和用量保留。

## 当前限制

- 一次试点扫描相关私信／群每会话最多500条，主上下文最多80条／16000字符；检索后最多120条。截断、未读媒体或部分记录均标记覆盖不足，限制新行动产生。尚非完整语义分段／历史归属引擎。
- 批次与行动使用来源锚点稳定ID及已有对象引用；同一事件换锚点的语义去重仍需真实样本评测。不能承诺任意模型输出不会重复或归错批。
- 确认目前按角色／批次／时间／其他类型归组；尚未细化到多个不同批次的独立确认案件。资料是有来源的记录，尚未实现完整字段冲突消解。
- 试点页面已支持查看、完成、暂停、角色确认和运行结果；正式产品中的改期、撤销、话术、搜索及全部页面布局仍待接入。独立HTML原型演示的能力不等于正式页面全部上线。
- 图片OCR、价卡理解、全量后台新引擎队列、旧结果代际切换、历史激活、材料匹配未交付。
- `--pilot`不取消已经在其他旧进程发出的请求；启动前应停止旧start/serve/worker。默认不带该参数仍运行原后台。
- 新引擎运行详情与旧“分析概览”队列分开；用量台账共用。语义效果需真实DeepSeek样本验收，自动化测试使用虚构来源和模拟模型。
