## 实施裁定与代价

1. 活动缓存过期时只读查询一次按账号派生当前证据，禁止只读连接写缓存；同步边界刷新缓存。代价：刷新前读取需扫描账号消息元数据，不能每个人重复扫描。
2. 超大discovery窗口由网关拒绝并保留临时候选，不截断后断言无需求；长历史分块由M3处理。代价：长窗口识别延后。
3. 运行模型／discovery factory注册等待经验证能力证据，最小连接检查不能自动开启付费整理。代价：验证和Task7接线前部分群发言者持续为临时候选。
4. Mac Keychain、真实容量／视觉及语义质量仍待本机验证；云端替身仅证明契约。代价：真实服务差异可能需要后续修复。
