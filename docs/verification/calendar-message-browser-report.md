## 一次独立只读审查

gpt-6-astra/high：Critical0、Important4、Minor1。四项重要问题均先失败回归后修复：

1. 切日期失败后旧消息冒充新日期：按日期／来源／关键词／代次绑定结果，不匹配时隐藏旧原文；保留独立来源菜单候选。
2. 点击正文误补页：只接受有方向的实际用户滚动，点击正文和程序定位不触发；回归同时验证插入锚点没有跳动。
3. 跨月键盘失焦：等待目标月份元数据确实到达且按钮可用，再恢复待聚焦日期，防止旧月数据短暂的非busy状态清掉焦点。
4. 日末连续他人消息时本人导航反向：最新窗口无本人消息时上一条指向当天最近一条本人发言，下一条禁用。

## 实施裁定及代价

- 按日过滤取代跨日连续浏览，这是用户最新确认的方案；上下文保留当天所有人物，跨天通过日历选择。代价：不自动拼接跨午夜对话。
- 日历蓝点按来源范围统计，关键词作用于右侧当天消息，回最新保留关键词。代价：某日有蓝点但当前关键词可能无匹配，界面明确显示空结果。
- 最新是已同步归档最新，不冒充实时微信；未来异常日期若有归档证据仍可查看。代价：真实来源时间错误需单独核实，不在展示层擅改。
- 自动补页需要实际滚动意图，每次有界读取，禁止初始定位无限吸入整日历史。代价：继续读取下一个窗口需要再次滚动。
- 云端验证与Mac实测分开，未连接真实模型、媒体或新的微信服务。代价：实机视口差异待用户验证。
