数据库包括账号、联系人、会话、成员、消息及修订、附件、游标、同步尝试、操作及运行项、账号设置。复合外键和唯一约束按账号隔离；普通消息必须有真实发送人，只有system／revoke事件允许人物归属为空。任务1只交付约束和存储结构，修订记录的业务写入由任务2实现。

连接由使用它的线程创建和关闭，启用外键、WAL及5秒busy timeout；迁移不使用会隐式提交的executescript，不提交调用方已有事务。健康接口只读打开现有数据库，丢失文件或版本异常返回503；启动失败不清库。服务工厂可注入Settings和Services，不构建全局微信／模型连接。

测试过程：基础实现前5项失败、9项夹具错误均为模块／依赖未实现；自审发现健康查询会重建丢失的数据库，新增回归先失败再修复，最终114项全部通过。当前云端沙箱的TestClient线程通知及端口绑定受限；同一组测试与loopback HTTP验证在外层云端执行成功，未依赖用户Mac或真实微信数据。审查由当前代理完成，未使用子代理。

本阶段没有自动同步、真实客户列表或模型调用。启动命令见[Mac验证指南](../MAC_SETUP.md)。
